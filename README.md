# 健康档案 · 原生 iOS

按病症收集病历与药方，保留原图和可修改的识别内容；用药提醒是当前药方的可选功能。

## 运行

- Xcode 26.3；iOS 17.3 及以上。
- 打开 `BillScan.xcodeproj`，选择 `BillScan` scheme 和 iPhone 模拟器运行。
- 真机运行需在 Signing & Capabilities 中配置自己的开发团队。
- 新档案使用系统 Vision 本机 OCR，无需配置云服务或下载模型。历史票据入口仍保留原项目相关依赖。

## 已实现

- 白色、鼠尾草绿、大圆角的 SwiftUI 档案首页，原生导航、弹层和按压回弹。
- 新建、重命名、归档、搜索、删除病症档案；按日期浏览和筛选病历／药方。
- 多页文稿扫描、相册图片导入、本机中文 OCR；原图保存、分页及双指缩放。
- 手动新增和编辑标题、就诊日期、机构、原文、备注以及药品名称、用量、频次、疗程。
- 当前／历史药方切换；药方归入历史或删除时取消相关通知。
- 用量和疗程缺失时保持待确认；不根据药名推断医嘱；非固定频次保留原文。
- 为已确认的药品设置本地通知，按起始日期、天数和每日时刻安排，疗程结束后停止。通知点击进入关联药方。
- SwiftData 本地持久化；原有 Receipt / Category 数据保留，可在“我的 → 查看旧版票据”进入。
- 首次使用为空档案，不向用户数据库注入示例资料。数据库打开失败时保留原数据并提供重试。

## 用药提醒边界

提醒须用户核对原药方并明确保存时间。系统权限关闭时显示原因，专注模式与设备设置也可能影响通知呈现。

每条提醒使用有限日期的系统本地通知，不创建无限重复通知。当前安排总量上限为 60 条；超限会明确拒绝新计划并保留旧计划，不宣称未安排的时间已覆盖。同一药方同一时刻的药品合并为一条提醒。长疗程可通过“本次提醒至”选择独立的提醒覆盖日期，不改动原药方疗程；详情会展示覆盖截止日，之后需再次打开药方继续安排。

## 验证

```sh
xcodebuild -project BillScan.xcodeproj -scheme BillScan \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  CODE_SIGNING_ALLOWED=NO test
```

单元测试覆盖：真实 Vision 识别、指令提取、缺失医嘱、时间间隔用法、持久化重开、级联删除、旧库升级、有限疗程日期、无效提醒计划、按药方取消通知。

UI 测试覆盖：档案／药方浏览、编辑取消、归档与恢复、手动新增保存、提醒设置。UI 截图保存在测试结果附件。

`--health-demo` 启动参数仅在 Debug 生效，使用内存数据库展示示例档案，用于 UI 测试和设计验收，不影响正常数据库。

## 真机验收

模拟器不能调用真实文稿摄像头。发布前还需用真机检查拍摄清晰度、多页扫描、锁屏通知、相册权限拒绝后的操作，以及真实医院版式和手写医嘱的识别效果。识别结果始终允许人工校正。
